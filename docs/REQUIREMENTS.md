# 함께봄 요구사항서

기준일: 2026-11-26 (KST). 팀의 정본 명세(개발명세 v1.8, 통합 기획서 v1.8, 기능·UI 매트릭스 v1.9, 상세 기능 카탈로그)를 공개 평가용으로 정리한 문서입니다. 원문은 비공개 저장소에 있고, 여기에는 현재 사실과 수락 조건만 옮겼습니다.

## 1. 개요

### 1.1 문제

부모님과 자동차로 국내 여행을 계획하는 성인 자녀는 일반 여행 앱에서 다음 정보를 한곳에서 얻기 어렵습니다.

- 주차·하차 지점에서 실제 입구까지 계단, 경사, 거리, 쉴 곳이 있는지
- 장애인 화장실, 엘리베이터, 휴식 공간이 있는지와 그 정보의 출처·확인 시점
- 부모님의 보행 가능 시간과 휴식 간격을 반영한 하루 일정
- 여행 당일 컨디션이나 날씨가 바뀌었을 때 남은 일정을 줄이거나 바꾸는 방법
- 일정과 주의사항을 다른 가족에게 읽기 전용으로 공유하는 방법

함께봄은 인기 순위보다 "가족의 이동 부담과 조건"을 기준으로 장소를 고르고, 접근성 정보를 출처와 함께 보여 주는 지도 중심 웹 서비스입니다.

### 1.2 사용자

| 사용자 | 설명 | 권한 |
| --- | --- | --- |
| 여행 작성자 | 부모님과의 여행을 계획하는 성인 자녀 | 조건 입력, 일정 작성·편집·재조정, 공유 링크 발급 |
| 여행 중 조작자 | 여행 당일 일정 화면을 쓰는 작성자 | 진행 표시, 컨디션 선택, 변경안 적용·되돌리기 |
| 읽기 전용 가족 | 공유 링크를 받은 가족 | 일정 지도와 공개 주소·시간·주의사항 보기만 가능 |
| 익명 탐색자 | 로그인 없이 홈과 지도를 보는 방문자 | 장소 탐색, 상세 보기 |

서비스 범위: 장소 탐색은 전국을 목표로 하고, 일정 작성은 서울·경기와 자동차 이동을 기준으로 합니다.

### 1.4 표기

우선순위: **Must** = 핵심(정본 P0), **Should** = 확장(정본 P1), **Could** = 후속(정본 P2). 평가 요건에 맞춰 앞당긴 항목은 비고에 적었습니다.

현재 상태는 다음 뜻으로만 씁니다.

| 표기 | 뜻 |
| --- | --- |
| 구현·자동 테스트 | 코드가 있고 저장소의 자동 테스트가 그 동작을 검사함. 실기기·실사용자 수락은 별도 |
| 부분 구현 | 코드가 있으나 수락 조건 일부가 아직 충족되지 않음 |
| 구현 중 | 작업 브랜치에서 개발 중이며 main에 병합되지 않음 |
| 계획 | 요구사항만 있고 구현하지 않음 |

자동 테스트 결과는 [VERIFICATION.md](VERIFICATION.md)에 있습니다. "운영 수락"(실기기·실데이터·실사용자 확인까지 끝난 상태)으로 표시한 요구사항은 아직 없습니다.

| NFR-04 | 비밀 관리 | 공급자 API 키는 서버 환경변수로만 쓰고 브라우저·저장소·문서에 값을 두지 않는다. 지도 SDK 공개 키는 공급자 도메인 제한을 쓴다 | 공개 스냅샷 동기화의 비밀값 패턴 검사, 번들에 키 처리 없음 테스트 |
| NFR-05 | 장애 격리 | 외부 API마다 시간 제한을 두고, 실패해도 화면 전체가 멈추지 않는다. 호출 한도 보호를 위해 캐시와 재시도 제한을 둔다 | [STABILITY.md](STABILITY.md) |
| NFR-06 | 재현 가능한 빌드 | 브라우저 번들은 6개 원본 파일에서 다시 만들 수 있고, 원본과 번들이 다르면 검사가 실패한다 | `scripts/build_core_modules.py --check` |
| NFR-07 | 배포·되돌리기 | main 병합 시 자동 배포하고, 문제 시 이전 정상 배포로 되돌린다 | [GIT_WORKFLOW.md](GIT_WORKFLOW.md) |
| NFR-08 | 자료 권리 | 이용 권리가 확인되지 않은 사진은 표시·재배포하지 않고 대체 표시를 쓴다. 공공누리 출처를 표기한다 | 사진 관련 단위 테스트 |
| NFR-09 | AI 안전 | 사용자 문장은 지시가 아닌 데이터로 다루고(프롬프트 인젝션 방어), 구조화 출력과 서버 재검증을 거친다. 안전 보장 표현·근거 없는 숫자는 제거한다. 호출 시간 제한·호출 횟수 제한을 둔다 | `tests/ai_assistant.test.cjs`(모킹) |
| NFR-10 | 동의 | 기기 저장 메모리·위치·피드백 저장은 사용자 동의 후에만 하고, 철회할 수 있다 | 구현 중(확인 안 됨) |

## 4. AI 활용 명세

| 기능 | AI 방식 | 상세 | 상태 |
| --- | --- | --- | --- |
| 자연어 조건 정리(F19) | 단일 LLM 호출 + 구조화 출력 | Claude Messages API(기본 `claude-haiku-5-5`), JSON Schema로 열거형 값만 받음. 서버가 허용 목록·날짜·인원을 다시 검증, 미리보기 후 사용자가 적용 | 구현·모킹 테스트, 운영 활성 |
| 가족용 일정 설명(F19) | 단일 LLM 호출 + 출력 필터 | 일정 자료(장소명·시각·이동시간·카탈로그 편의시설)만 입력. 자료에 없는 숫자·안전 보장 표현 문장 제거 | 구현·모킹 테스트, 운영 활성 |
| 여행 초안(F23) | AI Agent(도구 호출) | Claude가 `search_places`·`get_place_facts`·`get_weather`·`estimate_travel` 도구를 골라 호출하고, 도구 결과로 초안 작성 | 구현 중 |
| 일정 설명 RAG(F19·F24) | RAG | 공식 자료 카탈로그를 placeId·이름 일치로 검색(벡터 DB 미사용) → "검색된 공식 자료" 블록으로 프롬프트에 넣음 → 출처 표시 | 적용(일정 설명). 모킹 테스트로 확인, 운영 실제 응답 확인 안 됨 |
| 선호 기억(F25) | Long-term Memory | 동의한 선호만 기기 저장, 다음 요청 프롬프트에 포함 | 구현 중 |
| AI 생성 표시(F27) | 화면 규칙 | AI 결과에 생성 표시, 확인 전 미반영 | 부분 구현 |

RAG 적용 내용은 [AI_DESIGN.md](AI_DESIGN.md) §9.3, Agent·Memory 설계는 §9.2(설계만). 현재 구현은 [AI_INTEGRATION.md](AI_INTEGRATION.md).
