# 함께봄 팀원과 기여

> **팀 신고 기준 역할 분담**입니다. 아래 역할은 팀이 신고한 담당 영역이며, Git 커밋 작성자 기록과 1:1로 대응하지 않습니다.

## 1. 팀원

| 이름 | 역할 | 담당 영역 |
| --- | --- | --- |
| 남지현 | 팀장, 개발·통합 | 코드 저장소 운영, 프런트엔드·서버 API 개발 통합, Vercel 배포, CI·공개 스냅샷 동기화, AI 코딩 에이전트 작업 지시·검토·병합 |
| 이윤희 | 기획·요구사항·UX 설계 | 사용자 시나리오(부모님 동반 자동차 여행), 접근성 정보 기준(출처·확인일·정보 없음 구분), 7개 화면 흐름과 화면별 요구사항 |
| 백수현 | 데이터·검증 | 장소·공중화장실·사진 데이터 조사와 검수(출처·좌표·이용 권리 확인), 테스트 시나리오와 QA, 발표 자료 |

## 2. 커밋 기록에 대한 설명

- 저장소의 커밋은 팀장 남지현의 두 GitHub 계정(`jihyunnam`, `jihyuntesting-boop`)으로 통합 반영되었습니다. 계정별 커밋 수는 [COMMIT_LOG.md](COMMIT_LOG.md)에 있습니다.
- 팀 신고에 따르면 이윤희·백수현의 기획·데이터·검증 결과는 팀 협의를 거쳐 팀장이 문서와 코드에 반영했습니다. 따라서 두 사람의 이름으로 된 커밋은 없습니다. 이 문서는 특정 커밋을 특정 팀원이 작성했다고 주장하지 않습니다.
- 개발 과정에서 AI 코딩 에이전트(Anthropic Claude, OpenAI Codex)를 활용했습니다. 에이전트는 작업 브랜치(`claude/*`, `codex/*`)에서 코드와 문서를 작성했고, 팀장이 PR 검토와 CI 결과 확인 후 병합했습니다. 에이전트가 만든 변경도 팀장 계정의 커밋으로 기록되어 있습니다.
