# 함께봄 실사용자 피드백

기준일: 2026-11-26 (KST).

## 1. 현재 상태

**실사용자 피드백은 아직 수집되지 않았습니다.** 이 문서의 기록 표는 비어 있으며, 가상의 응답이나 예시 응답을 채우지 않습니다. 실제 응답이 들어오면 표와 집계를 갱신합니다.

목표: 부모님 동반 여행을 계획하는 서로 다른 실제 사용자 5명 이상(U01~U05, 추가 참여자는 U06부터).

## 2. 진행 방법

1. 지인·가족 중 부모님과 여행을 계획해 본 사람에게 아래 안내 문구를 보냅니다(자발적 참여).
2. 참여자는 운영 서비스에서 5개 과제를 해 보고 2분 설문에 답합니다.
3. 수집하지 않는 것: 실명, 연락처, 질병·건강 정보, 정밀 위치, 실제 집 주소. 테스트에는 가상의 여행 조건을 써도 된다고 안내합니다.
4. 불편하면 언제든 중단할 수 있고, 정식 출시를 약속하지 않습니다.
5. 응답은 참여 ID(U01~)로만 기록합니다. 평가 자료에 의견을 인용해도 되는지 따로 묻습니다.

### 과제

| 번호 | 과제 |
| --- | --- |
| T1 | 여행 만들기에서 지역·날짜와 부모님 보행·계단 조건 입력 |
| T2 | 지도와 추천 목록에서 장소 비교, 장소 상세에서 접근성 정보와 출처 확인 |
| T3 | 장소를 일정에 담고 순서·이동시간 확인 |
| T4 | 여행 중 화면에서 컨디션을 바꿔 변경안을 비교한 뒤 적용 또는 취소 |
| T5 | 공유 링크를 복사해 다른 기기나 브라우저에서 열기 |

## 3. 2분 설문 (7문항)

| 번호 | 질문 | 응답 형식 |
| --- | --- | --- |
| Q1 | 부모님과의 여행 계획에 가장 도움이 된 기능은 무엇인가요? | 객관식(조건 입력 / 추천 / 장소 상세 접근성 / 일정 / 여행 중 조정 / 가족 공유 / 날씨) |
| Q2 | 가장 어렵거나 헷갈린 단계는 무엇인가요? | 객관식(T1~T5 / 없음) + 한 줄 |
| Q3 | 장소 상세에서 "공공자료 안내"와 "정보 없음"의 차이를 이해했나요? | 예 / 아니오 / 잘 모르겠음 |
| Q4 | 컨디션을 바꿨을 때 완료·필수 일정이 유지된다는 점을 알아볼 수 있었나요? | 예 / 아니오 / 해 보지 않음 |
| Q5 | 공유 링크가 다른 기기에서 제대로 열렸나요? | 예 / 아니오 / 해 보지 않음 |
| Q6 | 글씨 크기·버튼 크기는 부모님이 보기에 적당했나요? | 1(매우 불편) ~ 5(매우 편함) |
| Q7 | 한 가지만 고친다면 무엇을 고치고 싶나요? | 자유 서술 |

설문 도구는 개인정보를 요구하지 않는 양식(예: 이름·이메일 수집을 끈 온라인 설문)을 씁니다.

불편하시면 언제든 그만두셔도 괜찮아요. 고맙습니다!

## 6. 반영 절차

1. 응답을 받은 날 기록 표에 옮기고 원본 응답은 비공개로 보관합니다.
2. 의견을 주제별로 묶고(예: 조건 입력, 접근성 표시, 일정, 공유) 건수를 셉니다.
3. 고칠 항목은 요구사항 ID와 연결해 작업 브랜치를 만들고 PR 본문에 참여 ID를 적습니다.
4. 반영한 PR 번호를 기록 표에 적고, 반영하지 않은 의견은 이유를 적습니다.
5. 집계(참여자 수, 과제별 성공/실패 수와 분모, 주제별 건수, 반영/미반영)는 5명 이상 응답이 모인 뒤 이 문서에 추가합니다.
