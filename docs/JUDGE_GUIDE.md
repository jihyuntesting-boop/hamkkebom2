> 상태: **초안**(2026-11-26). 팀 QA 담당이 운영 사이트에서 직접 따라 해 본 경로입니다. 화면 문구는 저장소 코드에 있는 것을 확인했지만, 아래 관찰 내용 전체를 이 문서 작성자가 다시 따라 해 보지는 않았습니다. 대표 명소 API가 외부 호출 한도에 걸리는 시간대에는 3·4단계 일부 장소가 보이지 않을 수 있습니다([VERIFICATION.md](VERIFICATION.md) 4절). 외부 호출 한도 대응과 남은 화면 수정이 반영된 뒤 다시 확인하고 확정합니다. 장소 세부페이지는 그사이 공식 출처 정보 22곳이 추가되어 아래 "피하면 좋은 경로"의 설명이 달라졌을 수 있습니다.

주소: https://hamkkebom-omega.vercel.app/ (휴대폰·PC 모두 가능, 로그인 없음)

## 5분 확인 순서

| 단계 | 할 일 | 보이는 것 (2026-11-26 관찰) |
| --- | --- | --- |
| 1. 홈 (30초) | 첫 화면을 보고 아래로 스크롤 | "좋은 곳보다, 함께 가기 편한 곳." 소개, 내 주변 관광지 지도(위치 권한을 거부하면 서울 시청 기준으로 표시하고 그렇다고 알려 줌), 사진으로 만나는 여행지(경복궁·북촌한옥마을) |
| 2. 여행 만들기 1단계 (1분) | 상단 "여행 만들기" → 지역 **서울**, 날짜 **"내일"** 버튼, 출발 희망 **10:00**, 집 도착 희망 **18:00**, 여행 형태 당일·자동차·2명 그대로 → "다음" | 아래쪽 "여행일 날씨 · 자동 조회"에 기상청 단기예보(기온·강수확률·발표 시각)가 나옵니다. 시각을 25:99처럼 잘못 넣으면 "분은 00~59 사이로 입력해 주세요"라고 막습니다. |
| 3. 이동 조건·선호 (40초) | 2단계: **15분 정도**, **가능하면 계단 피하기** → 다음. 3단계: **화장실 가까이** → "이 조건으로 장소 살펴보기" | 조건을 고르지 않고 "다음"을 누르면 선택하라는 안내가 나옵니다. |
| 4. 장소 고르기 (1분) | 계절 추천 코스 **"서울 궁궐과 한옥 골목 나들이" → "이 코스 장소 담기 (2곳)"**, 아래 목록에서 **국립중앙박물관 "일정에 담기"** → 상단 고정 바 "선택한 장소로 일정 만들기" | 비 예보가 있는 날에는 "날씨에 맞춘 여행지 제안"이 실내 시설을 먼저 보여 줍니다(문구는 예보에 따라 달라짐). 고정 바의 담은 장소 수가 바로 바뀝니다. |
| 5. 일정 확인·편집 (1분) | 생성된 일정표 확인 → "일정 편집" → 국립중앙박물관 "↑ 위로" → "편집 끝내기" | 장소·점심·휴식이 시간표로 배치됩니다(관찰 예: 10:25 경복궁 → 11:25 휴식 → 12:10 점심 → …). 순서를 바꾸면 도착 시각이 다시 계산되고 "일정 수정 내용을 이 기기에 저장했어요"가 나옵니다. "방문 전 확인할 점"에 출발·귀가 시각 반영 근거가 적힙니다. |
| 6. 컨디션 조정 (30초) | "컨디션에 맞게 일정 조정" → "조금 힘들어요" | 기존 일정과 변경 후 일정이 나란히 나오고 "유지/제외"가 표시됩니다. 적용하기 전에 미리보기를 확인할 수 있습니다. 적용 후 시간 재계산은 개선 중이라 이번 확인에서는 미리보기까지만 권합니다. |
| 7. 가족 공유 (30초) | 일정표 "가족에게 공유" → 확인 체크 → "공유 일정 미리 보기"(또는 링크 복사 후 새 탭) | 읽기 전용 일정이 열립니다. 편집 버튼이 없고, 원본을 고쳐도 이미 보낸 링크는 바뀌지 않는다고 안내합니다. 새로고침해도 원래 일정이 유지됩니다. |

## 사실대로 알려 둘 제약

- **이동시간은 실측이 아니라 예상치입니다.** 현재 장소 사이 이동은 "약 25분 (예상)"으로 넣습니다. 네이버 자동차 경로 연동 키가 운영에 등록되지 않아 실제 경로 시간으로 바꾸는 기능은 운영에서 동작하지 않습니다.
- 일정과 편집 내용은 **이 기기(브라우저)에만 저장**됩니다. 계정·서버 동기화는 없습니다. 공유 링크는 생성 시점 일정의 읽기 전용 사본이고, 만료나 회수 기능이 없습니다.
- 계단·경사·보행 정보는 장소마다 공개 자료의 범위가 다릅니다. 함께봄은 이동 가능 여부를 보증하지 않습니다.
- 일정 지역은 현재 **서울·경기**만 지원합니다. 장소·사진 정보는 한국관광공사 TourAPI와 이용 허락이 확인된 사진(출처 표기)만 씁니다.
- 날씨는 기상청 단기예보 기준입니다. 예보 범위를 벗어난 날짜는 날씨 제안이 나오지 않을 수 있습니다(먼 날짜는 확인 안 됨).
- 생성형 AI 기능(말로 여행 조건 적기, 일정 설명)은 운영에 API 키가 등록되지 않아 화면에 나타나지 않습니다([AI_INTEGRATION.md](AI_INTEGRATION.md)).
- 장소 상세의 "운영시간·요금·시설 더 보기"(전국 상세 조회)는 운영에서 꺼져 있습니다.
