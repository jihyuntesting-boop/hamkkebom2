기존 여행 일정 가져오기

이 페이지는 브라우저 안에서만 동작합니다. 부모님 이동 조건과 일정은 서버로 보내지 않습니다. 백업 파일은 개인정보가 포함될 수 있으니 가족 공유 링크나 공개 저장소에 올리지 마세요.

1. 기존 사이트에서 개인 백업 받기

아래 버튼으로 백업용 북마크 주소를 복사한 후 브라우저 북마크의 주소(URL)로 저장하세요. 기존 함께봄 열기에서 해당 북마크를 실행하면 이 기기에 저장된 일정 JSON이 내려받아집니다. 기존 저장값은 변경하지 않습니다. 기기마다 각각 실행해야 합니다.



2. 새 사이트에 가져오기
다른 함께봄 탭을 닫은 뒤 백업 파일을 선택하세요. 기존 신규 사이트 데이터가 있으면 먼저 따로 내려받고, 명시적으로 교체를 선택해야 합니다. 자동 합치기는 하지 않습니다.

3. 기존 가족 공유 링크 바꾸기
기존 v1 읽기 전용 공유 링크를 새 주소로 변환합니다. 저장된 개인 데이터는 링크에 넣지 않습니다. 예전에 보낸 메시지는 자동 수정되지 않으므로 새 링크를 다시 보내 주세요.
